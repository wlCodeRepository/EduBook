# EduBook Schoolhouse 全站重构计划

目标：重构所有现有页面的视觉语言和布局，建立国际语言学校课程手册式界面，而非继续叠加样式修补。

## 设计方向
- 海军蓝 #182d4b、纸白 #ffffff、浅蓝灰 #edf1f5、朱红 #c74b35、墨色 #243249、边线 #d8e0e8。
- 英文使用系统 sans，中文使用系统中文 sans；日期与计数使用等宽数字。正文14–16px，辅助文字不低于12px。
- 标识采用课程手册书签式字标；导航使用固定深蓝侧栏，头像在底部。
- 登录页为学校封面与登录表单双栏；老师页课表为主、统计和下一节课为侧栏；学生页采用选老师、选时间、确认的阶段布局；管理页采用目录式行列表。
- 单一特色是清晰的日期/课时排版；不引入渐变、玻璃或无意义宣传卡片。

## 实施
1. 盘点 App.vue 及账号/预约/课表组件，保留业务和权限接口。
2. 完整替换 styles.css，合并 workspace.css，删除旧版遗留选择器；统一所有控件状态。
3. 重构登录封面、角色页头、老师主侧栏、学生阶段标识、目录结构与日期组件。
4. 更新本地视觉夹具，覆盖登录、老师、学生和管理组件布局；在桌面/手机检查。
5. 补充实际交互测试，运行类型检查、全量测试、构建、diff检查。
6. 核对远端基线，提交合并并发布前端，核验线上资源。

验证边界：视觉夹具使用虚构样例，不代表线上真实数据写入成功；本轮不调整预约默认开放、15分钟档位、角色不可变或后端接口。
