# 个人中心与本周课表迭代

## 设计与取舍
- 老师首页采用七日课程概览：按老师时区的周一至周日展示课程，跨午夜课程出现在所覆盖的日期。保留待确认、已确认和已完成课程，拒绝/取消不占课表。完整拖拽日历暂不引入；纯列表不足以表达分布。
- 预约默认开放，未来每15分钟起约；整节课不得与占用预约或禁约时段重叠。数据库继续负责并发防超卖。
- 所有角色的个人中心可修改名称、时区和密码。账号与角色只读，管理员编辑接口拒绝角色/账号修改。
- 人员管理在服务端与前端排除当前操作人；新增账号、编辑资料、重置密码、删除继续保留。有关联课程历史的账号保留现有删除保护。
- 下拉框统一为轻量 Vue 组件，采用现有深蓝/青绿、实色面板、细边框与清晰焦点。支持键盘、搜索、空结果、选中态和移动端宽度。

## 数据与权限
无数据库结构变更。密码仅提交给 Supabase Auth，不存储到资料表或日志。管理接口仍需要认证并检查数据库中的 ADMIN 角色。角色只能创建时指定。
