# 工作台布局重构验证

## 实现
- 主区改为208px侧栏与自适应工作区，收窄页头、移除主页横幅、减少统计卡片装饰；标题改为统一无衬线字体。
- 头像菜单提供个人资料、修改密码、退出登录。AccountCenter 使用原生 dialog 约束焦点，关闭恢复头像焦点，保存期间禁止关闭/切换，密码组件卸载后清空状态。
- 个人信息不再是业务导航项，打开弹窗不会改变当前页面。
- TeacherBookings 分为待处理、已确认、历史，支持姓名搜索、加载/错误/空状态。
- 已结束的 CONFIRMED 在界面显示“已结束”，已结束的 PENDING 显示“已过期”，均归入历史且不再提供操作按钮。这是前端展示派生，不等同于立即修改数据库归档状态；原归档流程保持不变。
- 手机课表改成逐日紧凑列表；桌面保留七日分布。新增视觉样例在 tests/visual，使用虚构数据且不进入生产构建。
