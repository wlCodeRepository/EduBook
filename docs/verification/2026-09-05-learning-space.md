# Learning Space 验证与交接

## 已实现

- CSS 3D 数字教室：桌椅、窗、书本、灯、盆栽；老师姓名/时长联动；按钮切换视角；不加载模型、不依赖 WebGL，reduced-motion 关闭转场。
- 师生空间化顶部导航；管理员保留目录布局；登录使用同一场景。头像个人设置入口保持。
- 7天日期带、前后翻页、全天四组时间按钮；15分钟起点，一次选1–8连续课时；整段冲突阻止提交。长段冲突但短段可用时可调整节数。
- 课程票显示总时长、查看者/老师当地时间；成功回执与待确认占位分离，不把自己的新预约误报成冲突。
- 忙时段按当前周加两天尾部读取，覆盖最大8×240分钟；请求序号防止老师/日期切换后的旧响应覆盖。加载失败禁用预约并提供重试。
- 老师周课表按天打开禁约设置；禁约字段按账号显示时区转换UTC，拒绝不合法/不存在/重复的本地时间，避免静默偏移。当前为点击日期预填表单，不是拖拽画选区。
- 数据库保存 `lesson_minutes` / `lesson_count` 快照，旧记录按历史完整时长回填一节；老师列表与课表显示快照节数。

## 验证边界与发布顺序

本轮没有连接生产Supabase执行迁移，没有真实账号端到端写入，没有发布Pages，也没有合并主分支。离线夹具只在内存中模拟提交，不是后端成功证明。临时PostgreSQL采用最小auth角色/表替身，不能替代Supabase JWT联调。

发布前先备份及审阅 `docs/continuous-booking.md`，再执行版本化SQL；验证真实账号的单节、多节、确认/拒绝/取消及冲突后，部署本分支前端。现有create-booking参数签名不变，但未迁移的数据库仍会拒绝多节请求，不能仅发布前端。主分支和生产站点保持原版本。

## 本地复现

`npm run dev -- --host 127.0.0.1 --port 13755` 后打开上述夹具。正式入口需要原来的Supabase构建配置；不要向仓库写入任何私钥、口令或管理员Token。
