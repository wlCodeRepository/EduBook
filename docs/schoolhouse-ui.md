# Schoolhouse 界面规范与验证

## 视觉与布局

本轮统一登录、三角色工作台、人员目录、预约记录、课程设置、账号弹窗与下拉控件。深海军蓝作为导航书脊，朱红色标示当前日期和预约提交，白色内容配浅蓝灰页面。去除远程字体请求、旧样式覆盖文件以及旧版装饰样式；不新增 UI 库。

- 登录：课程手册封面与登录表单双栏；手机使用紧凑封面。
- 老师：宽屏周课表 + 右侧统计/下一节课；较窄屏统计下移，手机日程按天排列。
- 学生：老师目录、时间检查、课程确认三段布局；手机依次纵向排列。
- 管理员：账号目录使用筛选工具栏与信息行；新增账号为弹窗，窄屏表单单列。
- 账号：保留头像菜单，个人资料和密码采用原生 dialog；账号和角色保持只读。
- 控件：统一选择框、按钮、状态标签、焦点轮廓、错误/空状态；尊重 reduced-motion。

## 业务边界

本次没有修改后端函数、数据库、账号权限、通知策略或预约算法。仍是默认开放、15 分钟开始档位、待确认占时；UI 改版不等于重新验证线上增删改和并发写入。
